# Contributing Guide

Thank you for your interest in contributing to the Application Form Management System.

This document explains the preferred workflow for proposing changes, fixing
bugs, improving documentation, and adding new functionality.

---

## 1. Before Contributing

Before making changes:

1. Review `README.md`.
2. Review `SECURITY.md`.
3. Review the existing project structure.
4. Check the existing issue or change request if one exists.
5. Avoid unnecessary changes to unrelated files.

The canonical project structure should be preserved unless a structural change
is specifically required.

---

## 2. Development Requirements

Recommended environment:

- Node.js 20 or later
- npm
- PostgreSQL
- Git
